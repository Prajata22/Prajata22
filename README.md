# Prajata Samanta

Founder & CTO at [Utsav](https://utsavapp.in) · Kolkata, India

I build and run the engineering behind Utsav, a puja and spiritual-services booking platform for devotees in India, and Naxatra.ai, its astrology product. Small team, whole stack: mobile apps, web, backend, infrastructure, and the data work in between.

## What I work on

- **Utsav apps and web** — iOS and Android apps on React Native / Expo, the customer site on Next.js, and the internal admin platform. Shipped in five languages: Tamil, Telugu, Kannada, Hindi and English.
- **Backend and infrastructure** — Node.js + TypeScript services on GKE, Python / FastAPI services on Cloud Run, Postgres on Cloud SQL, Redis, and AWS Lambda + SQS for payment webhooks. Razorpay, PayU and PhonePe integrations.
- **Naxatra.ai** — horoscope and panchang engine on Swiss Ephemeris, with LLM-generated daily readings.
- **AI in operations** — multilingual content generation and support-chat tooling built on Anthropic, Gemini and OpenAI models.
